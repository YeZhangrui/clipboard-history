# 需求规格说明书 — 剪贴板历史 v1.0

> 文档编号：REQ-001　|　版本：v1.0　|　状态：已与用户确认（2026-09-07）

## 1. 项目背景与目标

用户需要一个运行在 **Windows 11** 上的桌面剪贴板历史软件，自动记录复制的内容（文字 + 图片），
支持按存储期限自动清理、按时间倒序浏览、置顶/删除、搜索，并能一键将历史内容放回剪贴板再次使用。

**目标用户**：不懂代码的普通用户。交付物为一个**双击即用的单个 exe**，无需安装任何环境。

## 2. 功能需求

### FR-1 自动记录
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-1.1 | 后台实时监听 Windows 剪贴板，内容变化时自动入库 | P0 |
| FR-1.2 | 支持两类内容：**文本**、**图片** | P0 |
| FR-1.3 | 软件窗口关闭/最小化到托盘后，依然持续监听记录 | P0 |
| FR-1.4 | 连续复制同一内容时合并为一条并更新时间，避免刷屏 | P2 |
| FR-1.5 | 开机自启：软件随 Windows 启动并在后台静默运行 | P1 |

### FR-2 存储期限
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-2.1 | 用户可设置存储期限：**1 天 / 3 天 / 5 天** | P0 |
| FR-2.2 | 到期内容自动清理（以记录的最后更新时间计算） | P0 |
| FR-2.3 | **置顶内容永不过期**，不参与自动清理，直到手动取消置顶或删除 | P0 |

### FR-3 历史浏览
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-3.1 | 主界面按**时间降序**展示记录卡片，置顶卡片固定在最前 | P0 |
| FR-3.2 | 文本卡片显示内容摘要（默认前 200 字），图片卡片显示缩略图 | P0 |
| FR-3.3 | 点击卡片内容：将该内容放回剪贴板，用户到目标窗口 Ctrl+V 粘贴 | P0 |
| FR-3.4 | 卡片支持**置顶 / 取消置顶**、**删除（单条）** | P0 |
| FR-3.5 | 顶部提供**一键清空**按钮（清空非置顶内容，二次确认防误触） | P1 |

### FR-4 搜索
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-4.1 | 顶部搜索框，按关键词实时过滤文本记录（忽略大小写） | P0 |
| FR-4.2 | 图片记录支持按时间筛选浏览（不参与文本关键词搜索） | P2 |

### FR-5 桌面悬浮面板（v1.5/v1.6 定稿：无悬浮球，常驻面板）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-5.1 | 设置/托盘可开启**桌面悬浮面板**：常驻置顶无边框卡片（默认屏幕右上角，位置+大小记忆） | P1 |
| FR-5.2 | 按住头部拖动换位置；**右下角手柄拖拽调整大小**（最小 240×240）；面板周围**无阴影/渐变**（干净贴边）；最近 20 条 + 搜索 + 点击复制原内容 + hover 删除 | P1 |
| FR-5.3 | 头部 ✕ = 关闭悬浮面板（托盘/设置勾选同步取消）；深浅主题自动适配 | P2 |

### FR-6 类型检索（v1.16 新增）
| 编号 | 需求 |
|---|---|
| FR-6.1 | 主窗口与悬浮面板搜索区旁提供**类型下拉：全部/文本/图片**，可与关键词组合过滤 |
| FR-6.2 | 图片类型下关键词忽略（图片不支持文本搜索），显示全部图片 |

### FR-7 快捷键（v1.16 新增；v1.20：双快捷键）
| 编号 | 需求 |
|---|---|
| FR-7.1 | **主界面快捷键**（默认 Ctrl+Shift+V）：主界面可见→**最小化**；隐藏/最小化→**唤出**（双向） |
| FR-7.2 | **悬浮面板快捷键**（默认 Ctrl+Shift+F）：面板显示→隐藏；隐藏→显示（双向） |
| FR-7.3 | 设置中两个快捷键均可换组合或**禁用**，保存即热生效；两角色预设无交集（不会重复注册） |
| FR-7.4 | 热键被其他程序占用时：注册失败自动禁用并在托盘气泡/状态栏提示（含 Win32 错误码） |

## 3. 非功能需求

| 编号 | 需求 |
|---|---|
| NFR-1 | 运行环境：Windows 11 x64，无需安装任何运行时 |
| NFR-2 | 交付形式：单个 .exe 免安装，双击即用 |
| NFR-3 | 启动速度 < 5 秒，后台占用内存目标 < 200MB |
| NFR-4 | 数据安全：历史数据仅保存在本地，不联网、不上传 |
| NFR-5 | 界面：简洁直观，主色调淡蓝色，详情见 `docs/design.md` |
| NFR-6 | 单实例：重复打开软件不再启动第二个进程，而是唤醒已有窗口 |

## 4. 验收标准（用户可亲自验证）

1. 复制一段文字 → 打开软件，能看到该文字卡片，点击后到记事本 Ctrl+V 能粘贴出来。
2. 复制一张图片 → 软件中出现带缩略图的图片卡片，点击后可在微信/画图等程序粘贴。
3. 设置存储 1 天 → 超过 1 天未更新的普通记录被自动清除；置顶记录保留。
4. 置顶一条记录 → 它出现在列表最上方，且删除过期内容时不会被清除。
5. 搜索关键词 → 列表实时过滤，只显示匹配的文字记录。
6. 电脑开机后软件在后台自动运行（无窗口），托盘图标可见，右键可退出。
7. （v1.4）设置勾选"桌面悬浮模式" → 桌面出现悬浮球，点击展开记录面板，点击条目即可复制，拖动球可换位置。

## 5. 待定/扩展项（不影响 v1.0 交付，后续版本再议）

- 存储天数扩展为任意自定义天数（如 7/30 天、永久保留）
- 图片压缩存储以节省硬盘空间
- 深色模式、卡片大小调节
- 快捷键唤出历史窗口（如双击 Ctrl）
- 常用/收藏分类、批量导出
