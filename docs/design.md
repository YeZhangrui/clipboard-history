# UI/UX 设计规范 — 剪贴板历史 v1.7（设计系统版 · 双主题 · Kazumi 风格）

> 文档编号：DESIGN-001　|　版本：v1.7　|　状态：已定稿（2026-09-07）
> v1.7 起风格参考 **Kazumi**（用户指定）：纯黑底/深靛蓝主色/大圆角/粗体白色标题/平面无渐变的现代美学。

设计关键词：**简洁、直观、淡蓝色（浅色）/ Kazumi 式深沉（深色）**。

## 0. 主题模式

三种模式（设置对话框可选，运行中热切换，无需重启）：
| 模式 | 行为 |
|---|---|
| 浅色 | 蓝白亮色（淡蓝底 #F3F7FB + 深靛蓝主色 #35618E） |
| 深色 | **Kazumi 风格**：纯黑底 #0F0F0F + 深靛蓝主色 #3E6FA5 + 深灰卡片 #1A1A1C |
| 跟随系统（默认） | 读取 Windows 深色/浅色设置（HKCU Themes/Personalize 注册表），每 2 秒轮询，系统切换即跟随 |

## 1. 色彩规范（WCAG AA 达标，浅色/深色双色板）

| 用途 | 浅色 | 深色（Kazumi） | 说明 |
|---|---|---|---|
| 主色 | `#35618E` | `#3E6FA5` | 深靛蓝：关键操作/焦点/选中（白字对比 ≥5.5:1） |
| 背景 | `#F3F7FB` 纯色 | `#0F0F0F` 纯黑 | 平面无渐变 |
| 表面（卡片/顶栏/对话框） | `#FFFFFF` | `#1A1A1C` | 顶栏 95%/97% 不透明 |
| 表面弱化（输入/软底） | `#EEF3F9` | `#242427` | hover `#E2EAF3` / `#2D2D31` |
| 主文字 | `#16202C` | `#F2F2F2` | 标题 700 字重粗体 |
| 次要文字 | `#52606E` | `#B4BAC2` | 分组标题（13px/700） |
| 元信息 | `#64748A` | `#8E959E` | 卡片时间/类型 |
| 置顶星标 | `#E9A13B` | `#F0B04A` | hover 淡金底 |
| 危险/删除 | `#E35D5D` | `#F07A7A` | hover 淡红底 |
| 卡片悬浮阴影 | 主色 22% 光晕 | 主色 38% 光晕 | hover 时开启 |

## 2. 圆角与字体（Kazumi 语言，v1.7）

- 圆角体系：卡片/顶栏 **16px**；按钮/输入框 **12px**；小控件/菜单 8px。
- 字体：`Microsoft YaHei UI`；标题 **18px/700**；分组标题 13px/700；正文 14px；元信息 12px。
- 窗口：默认 980 × 680px，最小 700 × 480px。
- 间距：8pt 网格；卡片内边距 16×12；列表间距 10px；区域间距 16px。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 顶栏 | 左：程序化小图标 + 标题（**禁用 emoji**，跨系统渲染不稳定）；中：搜索框；右：存储天数下拉 + 🗑 清空 + ⚙ 设置 |
| 设置对话框 | ⚙ 打开：开机自启开关（18px 圆角方块，选中蓝底）、存储期限下拉、**界面主题下拉（浅色/深色/跟随系统）**、数据位置与隐私说明；"确定"= 主色实心按钮/【取消】= 白/深色底 |
| 记录卡片 | 左：内容区；右：元信息（"图片 · 12:31"）+ 置顶星标 + 删除按钮；**hover 悬浮阴影**（主色 22% 模糊 26px 上浮感）+ 边框转蓝 |
| 置顶卡片 | 与普通卡片样式一致，另带金色星标（hover 淡金底）；固定排在置顶分组 |
| 分组标题 | "▍" 竖线装饰 + 12px/600 灰蓝文字 |
| 搜索框 | 放大镜为**控件内固定图标**（光标在其后）；无结果时显示居中提示 |
| 清空 | 点击后弹确认框："将清空所有未置顶记录，确定吗？" |
| 托盘菜单 | 左键双击打开主窗口；右键菜单：打开主窗口 / 开机自启开关 / 退出 |

## 5. 交互规范（全状态：默认/Hover/Active/Focus）

| 操作 | 行为 |
|---|---|
| 卡片 hover | 边框转浅蓝 + 悬浮阴影开启；离开阴影关闭（浅色主色光晕/深色亮蓝光晕） |
| 主题切换 | 设置中切换即**热生效**（无需重启）：QSS 重载 + 标题/搜索图标换色 + 卡片重建；跟随系统模式 2s 轮询注册表同步 |
| 按钮 hover/按压 | 背景变浅 + 边框加深；**pressed 背景再加深**（清空红系/设置蓝系/星标金系/删除红系） |
| 点击卡片内容区 | 内容放回剪贴板 → 卡片短暂高亮 + 底部提示"已复制，去粘贴吧 (Ctrl+V)" |
| 点击 ★ / ☆ | 置顶 / 取消置顶，卡片立即移动到置顶区 |
| 点击 ✕ | 单条删除，弹出确认框 |
| 搜索输入 | 实时过滤（300ms 防抖），只匹配文本记录 |
| 关闭主窗口 | 不退出程序，隐藏到托盘（首次隐藏时气泡提示一次） |

## 6. 桌面悬浮面板（v1.9）

| 元素 | 规范 |
|---|---|
| 悬浮面板 | 常驻置顶无边框卡片（默认右上角，**位置+大小记忆**），右下角手柄拖拽调大小（最小 240×240），**周围无阴影渐变** |
| 头部 | 图标 + 标题 + **🏠 召唤/收回主界面**（图标化，toggle：主界面隐藏→召出前台；显示→收回托盘）+ **✕ 收起**（图标化；收起≠退出模式） |
| 图标体系 | 面板内所有图标（🏠/✕/删除/缩放手柄）为**程序化线性图标**，与主界面放大镜/标题图标同一笔触与灰度（主题 token color），风格统一 |
| 顶栏入口 | 主窗口顶栏 **「▣ 悬浮」按钮**：模式关→开；开+可见→收起；开+已收起→再显示；激活态主色实心 |
| 条目 | 文本摘要 2 行 / 缩略图 + 时间；点击复制原内容（抑制自身监听）+ hover 删除 |
| 主题 | 跟随全局 token（双主题自动适配），所有颜色来自 QSS 变量 |

## 7. 无障碍与体验细节

- 全文对比度 ≥ 4.5:1（WCAG AA）：主文字 14.2:1、次要 4.9:1、按钮白字 4.6:1。
- 所有可点击控件 hover/active 均有明确视觉反馈；焦点输入框：白底 + 主色边框。
- 时间显示规则：今天"HH:MM"，今年"MM-DD HH:MM"，更早"YYYY-MM-DD"。
- 首次隐藏托盘时气泡引导一次："已最小化到系统托盘…"。
